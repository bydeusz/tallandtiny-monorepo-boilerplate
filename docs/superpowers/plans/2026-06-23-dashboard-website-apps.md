# Dashboard + Website Apps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two new Next.js apps — `apps/dashboard` (a future CMS) and `apps/website` (a public content site) — as exact mirrors of `apps/web`, wired to the NestJS backend, and reachable through the dev workflow.

**Architecture:** Both apps mirror `apps/web`'s stack and structure (Next.js App Router + React Query `Providers` consuming the shared, Orval-generated `@repo/queries`). No new backend code: the existing `customAxios` mutator already reads `NEXT_PUBLIC_API_URL`. The API's CORS allow-list and the `pnpm dev` auto-open script are widened to include the two new ports.

**Tech Stack:** Turborepo · pnpm · Next.js 16 · React 19 · Tailwind v4 · TanStack Query · `@repo/ui` · `@repo/queries` · NestJS 11 (CORS only).

## Global Constraints

- Package manager: **pnpm@10.28.2**; Node **>=22.12**; namespace **`@repo/*`** with **`workspace:*`** protocol.
- Ports: web **3000**, api **3001**, dashboard **3002**, website **3003**, Prisma Studio **5555**.
- New apps mirror `apps/web` **exactly** except name + port: `next@^16.0.0`, `react@^19.0.0`, `react-dom@^19.0.0`, `@tanstack/react-query@^5.62.0`, `tailwindcss@^4.0.0`, `typescript@^5.9.0`, `eslint@^9.17.0`.
- **Out of scope:** auth, CMS/website features, new API endpoints or Prisma models, shared-boilerplate extraction. Pages stay minimal placeholders.
- `next-env.d.ts`, `.env.local`, `.next/`, `*.tsbuildinfo` are **gitignored** — create `.env.local` locally but never `git add` it; `next-env.d.ts` is auto-generated by `next` on first build/dev (do not hand-write).
- Commit messages follow Conventional Commits and end with:
  `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`

**Note on testing:** these tasks scaffold static apps with no business logic, so there is nothing to unit-test (writing a smoke test for a placeholder page would be cargo-culted TDD). The test cycle for each task is **type-check + production build** via Turborepo (which builds workspace dependencies first), plus a dev-boot confirmation. Those are the gates a reviewer checks.

### Task 3: Wire new apps into the dev workflow (CORS + auto-open)

Widen the backend CORS allow-list and the `pnpm dev` auto-open script so browsers served from the new ports can call the API and the URLs open automatically.

**Files:**
- Modify: `apps/api/src/main.ts` (the `app.enableCors({ ... })` call)
- Modify: `scripts/dev.mjs` (the `TARGETS` array)

**Interfaces:**
- Consumes: ports `3002` (Task 1) and `3003` (Task 2).
- Produces: no code interface; widens runtime config only.

- [ ] **Step 1: Update CORS in `apps/api/src/main.ts`**

Replace this line:

```ts
  app.enableCors({ origin: 'http://localhost:3000' });
```

with:

```ts
  app.enableCors({
    origin: [
      'http://localhost:3000',
      'http://localhost:3002',
      'http://localhost:3003',
    ],
  });
```

- [ ] **Step 2: Update `TARGETS` in `scripts/dev.mjs`**

Replace this array:

```js
const TARGETS = [
  { name: 'web', url: 'http://localhost:3000' },
  { name: 'swagger', url: 'http://localhost:3001/api/docs' },
  { name: 'prisma studio', url: 'http://localhost:5555' },
];
```

with:

```js
const TARGETS = [
  { name: 'web', url: 'http://localhost:3000' },
  { name: 'dashboard', url: 'http://localhost:3002' },
  { name: 'website', url: 'http://localhost:3003' },
  { name: 'swagger', url: 'http://localhost:3001/api/docs' },
  { name: 'prisma studio', url: 'http://localhost:5555' },
];
```

- [ ] **Step 3: Type-check the API (gate)**

Run: `pnpm exec turbo run check-types --filter=api`
Expected: PASS, exit 0.

- [ ] **Step 4: Verify the CORS preflight allows the new origin**

Start the API: `pnpm --filter api dev` (second shell; wait for "Tintsmith API ready").
Then run a preflight probe for the dashboard origin:

```bash
curl -s -i -X OPTIONS http://localhost:3001/api/minis \
  -H 'Origin: http://localhost:3002' \
  -H 'Access-Control-Request-Method: GET' | grep -i access-control-allow-origin
```

Expected: a header line `Access-Control-Allow-Origin: http://localhost:3002`.
Repeat with `Origin: http://localhost:3003` → expect `Access-Control-Allow-Origin: http://localhost:3003`.
Stop the API afterwards.

- [ ] **Step 5: Commit**

```bash
git add apps/api/src/main.ts scripts/dev.mjs
git commit -m "$(cat <<'EOF'
feat(dev): allow dashboard + website origins and auto-open them

Widen API CORS to localhost:3002/3003 and add both apps to the pnpm dev
auto-open targets so all four apps come up together.

Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>
EOF
)"
```
